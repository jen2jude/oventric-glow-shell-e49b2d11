# Boutique Web Storefront Redesign

## Goal
Rebuild the public seller storefront in the selected boutique desktop direction while preserving all current seller data and actions.

## Implementation
- Replace the app-like public storefront composition with a wide, desktop-first shop presentation: panoramic brand cover, integrated seller identity, compact credibility metrics, and clear follow/message controls.
- Present Shop, Collections, Services, and About as refined web tabs that keep their existing behavior.
- Replace clipped desktop product rails with spacious responsive product grids, consistent media ratios, readable titles, ratings, and home-currency prices.
- Preserve selected-item highlighting, similar products, owner editing, profile messaging, verification, loading/empty states, and the separate compact app-shell experience.
- Use the existing light Oventric website header/footer, semantic design tokens, accessible controls, and restrained transitions.

## Responsive Behavior
- Desktop: wide storefront masthead and four-column product grids.
- Tablet: balanced two/three-column layouts with compact identity controls.
- Mobile: stacked seller identity, reachable actions, scrollable tabs, and two-column products without a bottom menu.

## Validation
- Check public and owner-facing controls remain wired to existing behavior.
- Verify desktop, tablet, and mobile rendering, overflow, keyboard/accessibility labels, and browser errors.
- Run the project type check.
