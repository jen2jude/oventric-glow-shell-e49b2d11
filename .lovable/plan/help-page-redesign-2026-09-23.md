# Help Page Redesign

## Goal
Transform the Help page into a complete, polished support destination using Oventric’s established Bright Spectrum aesthetic from the About page and product-publish experience.

## What will change
- Replace the compact guide panel with a full-width editorial Help experience.
- Add a clear support opening with search-style guidance and direct routes to common needs.
- Organize help into practical journeys: account and security, buying and downloads, selling and delivery, wallet and payouts, creators and community, and order support.
- Add an easy three-step support path: find an answer, check the relevant activity, report the issue with details.
- Add visible trust and transaction guidance for digital-only orders, escrow, reviews, refunds, seller earnings, and home-currency balances.
- Keep FAQ and Report a Problem as the main support actions and verify every destination.
- Ensure the footer and all content stay bright and readable on mobile, tablet, and desktop.

## Visual direction
- White surfaces with the multicolour category strip.
- Blue, violet, green, gold, and coral accents assigned consistently to help topics.
- Sora headings and Manrope body copy.
- Real support imagery, compact mobile headings, 10px corners, clear icons, and no dark content blocks.

## Technical details
- Rebuild only the Help route’s presentation and content; no commerce, wallet, support, or authentication logic changes.
- Reuse existing public navigation, footer, design tokens, Button, and typed route links.
- Add scoped Help-page tokens only where existing Bright Spectrum tokens are insufficient.
- Verify route metadata, links, mobile/tablet/desktop layout, readability, overflow, and browser errors.
